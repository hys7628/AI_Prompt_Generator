Review

같은 AI, 다른 결과: 질문 하나 차이

"구구단 만들어 줘"

  • 파이썬? 웹페이지? 엑셀? → AI가 마음대로 고름
  • "웹으로 해 줘" → "버튼 넣어 줘" → "글씨 키워 줘" → "모바일도"…
  • 5~6번 다시 시킴 = 토큰 5~6배

처음부터 이렇게

"초등학생이 쓰는 구구단 연습 웹페이지. 단을 고르는 버튼 2~9, 문제 10개, 정답이면 초록색. 모바일에서도 크게. HTML 한 파일로."

→ 1~2번이면 끝. 프롬프트를 잘 쓰는 건 결국 시간과 돈을 아끼는 기술이에요.

AI는 내가 말한 만큼만 압니다. 빠진 정보는 AI가 마음대로 채워요.

Why Prompt

왜 패턴을 하나씩 나눠서 배울까요?

어제는 기본 도구(역할·예시·형식·강도)를 배웠다면, 오늘은 상황별 해결법을 배워요.

요리로 치면 어제는 칼질·불 조절, 오늘은 "볶음밥 레시피", "찌개 레시피"예요. 상황에 맞는 레시피를 꺼내 쓰면 실패가 줄어요.

Why Patterns

바이브 코딩에서 오늘 패턴은 어디에 쓰일까?

바이브 코딩 = 코드를 직접 치지 않고 AI에게 말로 설명해서 프로그램을 만드는 것. 대화가 길어질수록 오늘 패턴이 빛나요.

① 기획요청을 다듬고 화면 목록 잡기
(질문 개선 · 아웃라인)
② 상황 고정"나는 초보, HTML 한 파일만"
(컨텍스트)
③ 코드 요청빠짐없이 한 번에
(프레임워크 RISEN)
④ 검토AI가 스스로 점검 · 확인 목록
(리플렉션 · 팩트 체크)
⑤ 반복 수정"/수정 버튼 키워 줘"
(메타 언어 · 무한 생성)

Game Play

게임 플레이 패턴이란?

게임의 목적, 규칙, 엔딩을 정해 주면 AI가 장면을 하나씩 보여 주고 선택지를 물어보며 게임을 진행합니다.

  • #입력: 게임 목적, 플레이어 할 일, 특징, 장애물, 진행 조건, 엔딩
  • #처리: "당신은 텍스트 기반 어드벤처 게임입니다"
  • #출력: 상태창 · 장면 설명 · 선택지
❤ 100 · 📍 서울 · 🎒 레이저 총 · 진행률 10%
하늘이 기괴한 보랏빛으로 물들고, 도시 위로 정체불명의 신호가 깜빡입니다…
1. 신호를 추적한다2. 시민을 대피시킨다3. 본부에 연락한다
What is it

실습 ① 외계인 침공 게임

1) #입력📍 Gemini 새 채팅 → [1)+2) 한 번에 복사] 버튼으로 함께 붙여넣기#입력 [게임 목적] - 외계인 침략 계획을 밝혀내고 저지함으로써 지구를 구하는 게임 [플레이어가 해야 할 일] - 지구의 여러 도시와 외계인 기지를 탐험한다 - 다양한 NPC들과 상호 작용하고 정보를 수집한다 - 논리적 사고를 통해 퍼즐을 해결한다 - 임무 수행에 도움이 될 유용한 아이템을 수집한다 - 외계인 전투에 참여해 적들을 물리친다 [플레이어의 특징] - 영웅적이고 용감하며, 항상 지구를 구하기 위해 최선을 다한다 [도전과 장애물] - 도시의 위험한 외계 생명체와 마주쳐 싸운다 - 외계인 기지에 설치된 위험한 함정을 헤쳐 나간다 - 외계인 지도자와 대결해야 한다 [게임 진행 조건] - 적에게 공격당하면 전투에 참여한다 - 수집한 아이템을 사용하여 장애물을 극복한다 - NPC와 상호 작용할 때 대화 옵션을 선택한다 - 게임 도중 내리는 선택이 이야기와 진행에 영향을 미친다 - 상태창을 통해 게임 진행 상태가 표시된다 - 반드시 한 장면씩 진행한다 [게임 엔딩] - 외계인 본거지에 도달하고 최후의 전투에 참여한다
2) #처리 · #출력📍 1)과 함께 붙여넣기 → 번호로 답하며 진행#처리 당신은 "텍스트 기반 어드벤처 게임"입니다. 당신의 목표는 외계인의 침략을 저지하고 지구를 안전하게 지키는 게임을 대화 형식으로 제공하는 것입니다. 상단의 입력 내용을 게임 전체에 반영해 전체 구조를 설계합니다. 설계 내용을 설명할 필요는 없습니다. 대화 형식으로 지금부터 게임을 시작합니다. #출력 [상태창] [장면 설명] [선택지]

NPC = 게임 속에서 내가 아닌 등장인물. 번호를 골라 답하면 다음 장면으로 넘어갑니다.

방법 2 · 여러 버전 제시📍 참고용 (틀) · 실습은 다음 장제 질문을 3가지 다른 방향으로 개선해 주세요 각 버전이 어떤 목적에 맞는지 설명하고 제가 선택하면 그 버전으로 답하세요
방법 3 · 문제 진단 먼저📍 참고용 (틀) · 실습은 다음 장제 질문의 문제점(모호함, 잘못된 전제, 누락된 맥락)을 먼저 지적하고 수정된 질문으로 답변하세요
