Prompt Engineering DAY 1

프롬프트란?

프롬프트는 ChatGPT·Gemini·Claude 같은 AI(거대 언어 모델, LLM)에게 우리가 평소 말(자연어)로 주는 명령입니다.

  • AI의 답은 정답이 아니라 "가장 그럴듯한 답(확률)"
  • 설명이 두루뭉술하면 → 흔하고 뻔한 답
  • 설명이 구체적이면 → 내가 원하는 범위 안에서 답

AI는 "지능이 높은 초등학생"

설명을 잘해 주면 기가 막히게 해내지만, 대충 말하면 엉뚱하게 합니다.

"AI가 바보 같다"고 느낄 때는 대부분 설명이 부족할 때입니다.

What is a Prompt

프롬프트가 왜 중요할까요?

같은 AI, 같은 날, 같은 질문인데 누구는 쓸 만한 답을 받고 누구는 뻔한 답을 받습니다. 차이는 프롬프트예요.

"메일 써 줘""베트남 바이어에게, 샘플 발송을 알리는, 정중한 영어 메일, 5줄"
누구에게? 무슨 내용? 몇 줄? → AI가 마음대로 채움필요한 정보가 다 있음 → 바로 쓸 수 있는 결과

식당 주문과 같아요

"아무거나 주세요" → 사장님 마음대로

"김치찌개 2인분, 덜 맵게, 12시까지 포장" → 원하는 그대로

프롬프트를 잘 쓰면 다시 시키는 횟수가 줄어듭니다. 업무에서는 이게 곧 시간이에요.

Why Prompts Matter

왜 이렇게 단계별로 나눠서 배울까요?

AI가 엉뚱하게 답하는 이유는 몇 가지로 정해져 있어요. 기법 하나 = 그 문제 하나를 고치는 도구입니다.

운전을 배울 때 출발·차선 변경·주차를 따로 연습하고, 나중에 도로에서 한꺼번에 쓰는 것과 같아요.

Why Step by Step

바이브 코딩에서 프롬프트는 어디에 쓰일까?

바이브 코딩 = 코드를 직접 치지 않고, AI에게 말로 설명해서 프로그램을 만드는 방법. 그래서 프롬프트가 곧 설계도입니다.

① 기획무엇을 만들지 AI와 정리
(역질문 · 대안)
② 요구사항기능·화면을 정리해 전달
(지침형 · 마크다운)
③ 코드 생성Claude · VS Code에서 코드 받기
(페르소나 · 예시)
④ 수정"버튼 48px로, 기존 기능은 그대로"

⑤ 오류 해결에러를 쪼개서 원인 찾기
(레시피 · 검증자)

"계산기 만들어 줘" 한 줄이면 AI 마음대로 만들어요. 오늘 배우는 기법으로 설명하면 내가 원하는 그대로 만들어집니다.

Overview

① 서술형: 상황을 이야기하듯

AI가 상황을 이해하도록 역할, 배경, 목적을 문장으로 설명합니다. 대화하듯 편하게 쓰는 방식이에요.

  • 장점: 자유롭고 유연함
  • 단점: 쓸 때마다 상황을 다시 설명해야 함
실습 · 서술형📍 Gemini 새 채팅에 붙여넣기 → Enter당신은 10년 경력의 무역 전문가입니다. 중소기업 수출 담당자가 HS code를 처음 배우는 상황입니다. 이 사람에게 HS code의 개념과 중요성을 설명해 주세요.

② 지침형: 규칙을 번호로

수업정리본 예시 (코드 작성 규칙)📍 참고용 (읽어 보기)1. 함수명은 snake_case로 작성 2. 각 함수의 docstring 포함 3. 예외 처리 반드시 포함 4. 결과는 json 형식으로 반환

snake_case = 단어 사이를 밑줄로(my_name) · docstring = 함수 설명문 · 예외 처리 = 오류 대비 · json = 데이터 정리 형식

Instruction

What is a Shot

제로샷: 예시 없이 바로

실습 · 제로샷📍 Gemini 새 채팅에 붙여넣기 → Enter이 제품 정말 맘에 들어

아무 기준도 없으니 AI는 "그 제품이 왜 좋으셨어요?"처럼 자기 마음대로 길게 반응합니다.

하나 더📍 같은 방법으로 새 채팅에강아지에 대해서 설명해주세요

Markdown

왜 마크다운을 쓸까?

AI는 글을 한 덩어리로 읽지 않고 잘게 쪼개서(파싱) 이해합니다.

  • 파싱: 글을 의미 단위로 쪼개는 것
  • 마크다운: #, -, > 같은 기호로 제목·목록·강조를 표시하는 간단한 문서 작성법
  • 기호로 구분해 주면 AI가 역할·조건·출력을 헷갈리지 않음 → 더 정확하고 일관된 답

서술형과 비교하면

서술형도 나쁘지 않지만 두루뭉술하고 AI가 알아서 해석합니다. 마크다운은 체계적으로 관리할 수 있어요.

꼭 써야 하는 건 아니지만, 쓰면 프롬프트 관리가 쉬워집니다.

Batch Questions
